## INSTRUCCIONES PARA EJECUTAR FRONT END Y BACK END
Una vez clonado o decargado el proyecto se debe ejecutar npm install en cada carpeta.

# 1. Clonar el repositorio
git clone <URL_DEL_REPOSITORIO>

# 2. Entrar a la carpeta del proyecto
cd jorge-1171

# 3. Entrar al backend e instalar dependencias
1 paso: cd server
2 paso: npm install
3 paso: Regresamos a carpeta raíz -> cd ..

# 4. Entrar al frontend e instalar dependencias
1 paso: cd client
2 paso: npm install

## INSTRUCCIONES PARA CORRER EL FRONT END Y BACK END
1 paso: En la misma terminal regresamos a la carpeta raíz jorge-1171/ -> cd.. 
2 paso: Una vez en ella ejecutamos el comando -> code .

Esto abrira visual studio code (Si no se necesita instalar)

3 paso : Tecleamos la combinación de teclas ctrl + ñ -> Esto abrira nuestra Terminal

# BACKEND (EXPRESS)
Abrir Terminal 1
Importante antes de correr el front end primero se debe ejecutar 

npm run dev desde la carpeta server/

# FRONTEND (REACT CON VITE y TYPESCRIPT)
Abrir Terminal 2 -> dar click en el + a la derecha
procedemos a ir a la carpeta client/

Una vez en la terminal poner ->

npm run dev
